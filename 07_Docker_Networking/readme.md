## Task 4: Docker Overlay Network

A Docker overlay network allows containers running on different Docker hosts to communicate with each other through a virtual network.

Overlay networks are commonly used with Docker Swarm for multi-host container communication.

They are useful for distributed applications where containers running on different Docker hosts need to communicate with each other.
